## 📖 Overview

**Placement 20** is a curated collection of LeetCode questions designed to help students ace coding interviews for placement season. These problems cover the essential data structures and algorithms patterns that companies ask during campus placements and off-campus drives.

Created using [LeetHub](https://github.com/QasimWani/LeetHub).

> 🎯 **Target:** Campus placements, off-campus drives, coding interviews

---

## 📊 Problem Categories

| Category | Focus |
|----------|-------|
| 🔢 Arrays | Trapping Rain Water, Jump Game, etc. |
| 🌳 Trees | Binary Tree Traversals, BST Validation, etc. |
| 🔄 Graphs | Graph traversals, Cycle detection, etc. |
| 🔢 Dynamic Programming | Min Path Sum, Combination Sum, etc. |
| 🔗 Linked List | List operations, Cycle detection, etc. |
